The hand-off cards show what the workflow chose. The changed-files card renders the document's `actions` on every file and folder, with `{path}` replaced by the node's host path, and keeps the "open in the file explorer" action on files. The terminal hand-off card shows the document's `title` and `description`, or neutral defaults, and a "Continue the run" button that fires the document's transition. The `handoff` feature renders cards in the run timeline and has no sidebar panel.

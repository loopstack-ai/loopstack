We're announcing the release of Loopstack 0.14.0, a major step forward in making AI-powered workflow automation more flexible and developer-friendly.

This update introduces several high-requested features and refinements across the entire platform, all designed to help you build smarter workflows with less friction.

Execute workflows with arguments

You can now trigger workflows directly from the Loopstack Studio frontend while passing custom parameters. Instead of adjusting workflow logic manually, you can now tailor every run to the exact context you need.

Configurable UI forms & actions

Loopstack 0.14.0 introduces a simpler way to design workflow and pipeline interfaces. You can define your inputs, actions, and UI behavior through configuration, which means that automation tools now adapt to you, not the other way around.

Support for Vercel AI Elements

Working with Vercel AI Elements is now as seamless as possible. You can integrate AI-powered interface components directly into Loopstack Studio workflows, enabling, richer user interactions powered by modern AI UI primitives.

Quality improvements across the board

stability improvements

bug fixes reported by the community

Loopstack is now faster, more stable and more predictable than ever, especially for complex workflows and long-running automation paths.
